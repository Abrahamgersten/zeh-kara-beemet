# הקמת הגיליון — מנויים - זה קרה באמת

זה גיליון תצוגת-ניהול חד-כיוונית (מ-Supabase אליו) — **לעולם לא עורכים בו ידנית** ומצפים שזה "יחזור" למערכת. לתיקון שורה (למשל מקרה קצה של אימייל לא-תואם) — לתקן ישירות בטבלת `subscribers` ב-Supabase, והגיליון יתעדכן לבד בסנכרון הלילי הבא.

## שלב 0 — יצירת הגיליון (אם עוד לא קיים)

1. [sheets.google.com](https://sheets.google.com) ← גיליון ריק חדש ← שם: **"מנויים - זה קרה באמת"**.
2. שמור את קישור הגיליון (יופיע בשורת הכתובת) — נצטרך אותו בעתיד.

## שלב 1 — הדבקת הקוד

1. פתח את הגיליון.
2. בתפריט: **Extensions / הרחבות ← Apps Script**.
3. מחק את כל התוכן שכבר שם (`function myFunction() {}`).
4. פתח את הקובץ [`Docs/AppsScript.gs`](AppsScript.gs) מהתיקייה הזו, העתק את **כל** התוכן, והדבק בעורך.
5. **חשוב: לפני השמירה, שנה את השורה הראשונה של `SECRET`** (`var SECRET = 'REPLACE_ME_WITH_A_RANDOM_SECRET';`) למחרוזת אקראית משלך — כל דבר, למשל 20-30 תווים אנגליים/מספרים. שמור את הערך הזה בצד, נצטרך אותו בשלב 4.
6. שמור (Ctrl+S / סמל הדיסקט).

## שלב 2 — הכנת הלשונית (הרצה חד-פעמית)

1. חזור לגיליון עצמו (טאב הדפדפן, לא עורך הסקריפט) ורענן את הדף (F5) — יופיע תפריט חדש בשם **"מנויים"** בסרגל התפריטים העליון.
2. לחץ **מנויים ← הקמה ראשונית (הרצה חד-פעמית)**.
3. בפעם הראשונה גוגל תבקש הרשאה ("This app isn't verified") — זה תקין (הסקריפט שלך, לא של צד שלישי): **Advanced/מתקדם ← Go to (שם הפרויקט) (unsafe) ← Allow/אישור**.
4. תופיע הודעה שהלשונית הוכנה עם כל העמודות.

## שלב 3 — פריסה כ-Web App

1. עדיין בעורך הסקריפט: **Deploy / פריסה ← New deployment / פריסה חדשה**.
2. ליד "Select type" (סמל הגלגל שיניים) ← **Web app**.
3. הגדרות: **Execute as: Me** (את/ה), **Who has access: Anyone**.
4. **Deploy / פריסה** ← אשר הרשאות שוב אם מתבקש.
5. יופיע **Web app URL** (מתחיל ב-`https://script.google.com/macros/s/.../exec`) — **העתק אותו**.

## שלב 4 — חיבור ל-Supabase

**הכי פשוט — שלח לרוני:** תפתח שיחה חדשה איתי ("רוני המתכנת") ותכתוב "הנה קישור ה-Web App למנויים: `<הקישור שהעתקת>`, והסוד: `<הסוד ששינית בשלב 1>`" — אני אעדכן את הסודות ב-Supabase Edge Functions (`SHEETS_WEBAPP_URL`, `SHEETS_WEBAPP_SECRET`) ואפרוס מחדש.

**עצמאי, בלי לחכות:**
1. [supabase.com](https://supabase.com) ← הפרויקט של "זה קרה באמת" ← Edge Functions ← Manage secrets.
2. הוסף/עדכן:
   - `SHEETS_WEBAPP_URL` = הקישור שהעתקת בשלב 3.
   - `SHEETS_WEBAPP_SECRET` = הסוד ששינית בשלב 1 (בדיוק כפי שהוא בקוד ה-Apps Script).

## איך יודעים שזה עבד

אחרי התשלום הבא (או אחרי שורת בדיקה שרוני מכניס ידנית ב-Supabase לצורך בדיקה) — שורה חדשה תופיע בלשונית "מנויים" תוך שניות. אם לא — זה בסדר גמור: עד שהשלב הזה בוצע, המערכת ממשיכה לעבוד כרגיל (התחברות, זיהוי מנוי), רק בלי הראייה בגיליון. אין מה "לתקן בדחיפות".

## אזהרה אחת (לקח מהאפליקציות הקודמות)

**אל תשנו ידנית את שמות העמודות** (שורת הכותרות) אחרי ההקמה — הסנכרון מזהה כל שדה לפי שם העמודה המדויק. אם תרצו לשנות ניסוח של עמודה, בקשו מרוני לעדכן את הקוד יחד עם זה, לא רק בגיליון. **וגם: לא לערוך שורות קיימות בגיליון עצמו** — זה לא זורם חזרה למסד הנתונים (ראו למעלה).
