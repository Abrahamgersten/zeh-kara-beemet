# זה קרה באמת

פלטפורמת תכני אודיו ותוכן לילדים ולכל המשפחה, בעיצוב שאול מ"אי היהלומים" (ללא אפקט הכוכבים הנוצצים - הוא הוחלף ברקע חם ושקט, מתאים יותר לתוכן הזה).

אתר סטטי טהור (HTML/CSS/JS ללא תלויות בנייה), עם תמיכת PWA (אפשר "להתקין" למסך הבית בנייד).

## מבנה

```
index.html          - כל הדף (הדר, הירו, "על הפרויקט", ניווט קטגוריות, הקטגוריות עצמן מוזרקות ב-JS)
css/style.css        - כל העיצוב
js/app.js            - כל התוכן (מערך CATEGORIES) + כל הלוגיקה (נגן, לייטבוקס, מצא-הבדלים, אקורדיון שו"ת)
assets/images/       - תמונות (כרגע: זוג ה-SVG של "מצא את ההבדלים" בלבד)
assets/audio/        - כאן יעלו קובצי mp3 של הפרקים (התיקייה ריקה כרגע)
icons/, manifest.json, sw.js - תמיכת PWA
```

## איך מוסיפים תוכן אמיתי

כל התוכן מוגדר במערך `CATEGORIES` בתחילת `js/app.js`. כל קטגוריה היא אובייקט עם `episodes`. כרגע כל הפרקים הם **תוכן לדוגמה** (`sample: true`) שנועד להמחיש את מבנה הכרטיס - הם מסומנים בתג "תוכן לדוגמה" באתר עצמו.

**להוספת/החלפת פרק בקטגוריית אודיו** (סיפורי צדיקים / נפלאות הבריאה / מה בפרשה / רעיון בפרשה / אור בהשכלה):
1. מעלים את קובץ ה-mp3 לתיקיית `assets/audio/<שם-קטגוריה>/`.
2. מעלים תמונת שער (jpg/png/webp) ל-`assets/images/`.
3. באובייקט הפרק המתאים ב-`CATEGORIES`, ממלאים:
   - `title` - כותרת הפרק.
   - `description` - הטקסט שמסביר במה עוסק הפרק (זה מוצג תמיד ליד הנגן).
   - `image` - הנתיב לתמונת השער (במקום `null`).
   - `audio` - הנתיב לקובץ ה-mp3 (במקום `null`).
4. מוחקים את `sample: true`.

כל עוד `audio` הוא `null`, יוצג באתר תג "ההקלטה תעלה בקרוב" במקום נגן שבור. כל עוד `image` הוא `null`, תוצג תמונת placeholder עם אייקון הקטגוריה.

**להוספת "מצא את ההבדלים"**: שני קבצי תמונה (`imageA`, `imageB`), `diffCount` (מספר ההבדלים), ו-`spots` - מערך נקודות `{x, y}` באחוזים (0-100) שמסמנות איפה כל הבדל נמצא, כדי שכפתור "הצג פתרון" יציג עיגול מדויק במקום הנכון בשתי התמונות.

**להוספת "מה לעשו״ת"**: `question` ו-`answer` בלבד. **שימו לב:** לפני העלאת שאלה הלכתית אמיתית, יש לוודא שהתשובה נבדקה ואושרה על ידי רב מוסמך - זה תוכן שילדים ילמדו ממנו, לא רק בידור.

## הרצה מקומית

אין צורך בהתקנת שום דבר - זה HTML/CSS/JS טהור. די בפתיחת `index.html` בדפדפן, או (מומלץ, כדי ש-service worker ו-manifest יעבדו כמו שצריך) בהרצת שרת סטטי פשוט מתיקיית הפרויקט, למשל:

```
python -m http.server 8000
```

ואז גלישה ל-`http://localhost:8000`.
